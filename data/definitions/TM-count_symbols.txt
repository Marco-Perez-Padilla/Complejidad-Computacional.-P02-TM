# Turing machine for: given a word over {a,b}, replace it with the count
# of 'b's in unary, followed by a blank separator, followed by the count
# of 'a's in unary; a zero count is written as a literal '0'. The head
# ends on the first character of the result on tape 1. Example:
# abbabaabb -> 11111 . 1111, aa -> 0 . 11.
#
# Three tapes: tape 1 holds the input (and ends up holding the result),
# tape 2 counts the b's and tape 3 counts the a's, each as a block of 1s.
#
# q0: one pass over the input. Each symbol is erased to 'X' on tape 1
#     and a '1' is written on the counting tape of its type, whose head
#     moves LEFT, so after the pass it sits on the blank just left of the
#     block and one step right lands on the block's first digit, without
#     having to rewind anything.
# q1: rewinds tape 1 to its start (the blank left of the input is the
#     sentinel).
# q2-q4: writes the b-count on tape 1 from tape 2 (a '0' if it is empty),
#     then the blank separator. q5-q7: same for the a-count from tape 3.
#     The result is always longer than the input, so every cell of the
#     input is overwritten and no 'X' is left behind.
# q8-q10: walk tape 1 back to the first character of the result. The
#     separator is a blank too, so a blank only counts as the left
#     sentinel if the cell before it is also blank.
